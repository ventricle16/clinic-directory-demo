# clinic-directory-demo

## Overview
This is a  MVP demo of an  Clinic Directory platform. It includes clinic listings, search and filter capabilities, clinic profile pages, appointment request forms, and an admin dashboard simulation. This demo is built using **HTML, CSS, and JavaScript** and is designed to showcase the functionality and UI of a real healthcare directory platform.

## Features

### Clinic Directory
- Displays multiple clinic listings with **name, location, and specialty**
- **Hover animations** for cards to enhance visual appeal

### Search & Filter
- Live search by clinic name
- Filter clinics by location**

### Clinic Profile Page
- Click **“View Profile”** to see detailed information about the clinic
- Includes **embedded Google Map** showing clinic location
- Includes **“Request Appointment”** button that redirects to clinic booking system

### Appointment Request Form
- Modal form collects **Full Name, Email, and Phone**
- Redirects to the clinic’s booking page after submission

### Admin Dashboard Simulation
- Add new clinics dynamically
- Instantly updates the directory to reflect new entries
- Demonstrates how a real admin panel could function

### UI Enhancements
- Modern, clean **Roboto font**
- **Gradient header** with shadow
- Cards and buttons with hover effects and transitions
- Responsive layout suitable for desktop and mobile

## How to Use
1. Clone or download the repository.
2. Open `index.html` in a browser.
3. Use the search input and location filter to find clinics.
4. Click **View Profile** to see detailed clinic info.
5. Click **Request Appointment** to simulate booking.
6. Use the admin section to add new clinics dynamically.

## Technologies Used
- HTML5
- CSS3 (Flexbox & Grid, Animations, Transitions)
- JavaScript (ES6+ for DOM manipulation and event handling)
